# Neo Geo hardware facts

Every hardware fact the Neo Geo code uses is a row here. Tags: `[D]` datasheet, `[H]` documentation, `[O]` observed in the
reference emulator (FinalBurn Neo, a black box through its libretro core), `[H?]` unresolved. No code, table or constant is
copied from any emulator.

| ID | Fact | Source | Used by |
|---|---|---|---|
| N1 | A cartridge set is a zip whose file extensions name the regions: `.p<n>` the 68000 program, `.s<n>` the fix layer, `.c<n>` sprite data in pairs (odd-numbered file the even bytes, the next file the odd bytes), `.m<n>` the Z80 program, `.v1<n>` the first sample region and `.v2<n>` the second; a set with only single-digit `.v` files has one region. Numbers order the files. Sets seen: Cyber-Lip (P 512 KB, S 128 KB, C 3 MB, M 128 KB, V1 2 MB, V2 512 KB), Fatal Fury (P 640 KB: a 512 KB and a 128 KB file, whose place in the address space is `[H?]`), Aero Fighters 2 (P 2 MB, C 8 MB, V 3 MB) | [O] the file names and sizes of the owner's sets (RomM platform 79) | `neo-set` |
| N2 | The BIOS is one zip of 34 files (`neogeo.zip`: `sp-s2.sp1`, `sp-u2.sp1`, `uni-bios_*.rom`, `000-lo.lo`, `sfix.sfix`, `sm1.sm1` and others); the machine picks one 128 KB 68000 BIOS, the fix tiles `sfix.sfix`, the zoom table `000-lo.lo` and the Z80 BIOS `sm1.sm1`. Which BIOS file FBNeo uses by default and what each is called by the hardware is `[H?]` | [O] the zip's listing; [H?] the roles | none yet |
| N3 | Reference output: FinalBurn Neo v1.0.0.03 (GIT2b0c1c0) libretro core reports 304 x 224 pixels, 59.18 fps, 47995 Hz audio; Cyber-Lip shows the NEO-GEO logo screen (Pro-Gear Spec) at frame 600 | [O] `libretro_run.py --info`, 2026-10-31 | scenarios |
| N4 | Clocks: master 24 MHz; 68000 at 12 MHz, Z80 at 4 MHz, YM2610 at 8 MHz, pixel clock 6 MHz; a frame of 384 x 264 pixel clocks is about 59.185 Hz | [H?] neogeodev wiki from memory, to confirm; [O] 59.18 fps agrees | none yet |
| N5 | The cartridge's program ROM is at `$000000-$0FFFFF` (vectors and the first bank) and a second bank window at `$200000-$2FFFFF`; with a 2 MiB program the two halves are swapped: the file's second MiB is at `$000000` and its first MiB at `$200000` | [H] neogeodev wiki "68k memory map", "P ROM" (found by search, 2026-10-31); [O] Aero Fighters 2's file starts with `20 00 44 01` (a first MiB that is not the vector table) | `neogeo` |
| N6 | Work RAM is 64 KiB at `$100000-$10FFFF`, mirrored through `$1FFFFF` on cartridge systems; its top (`$10F300-$10FFFF`) is used by the BIOS | [H] wiki "68k memory map", "68k user RAM" | `neogeo` |
| N7 | The system ROM is 128 KiB at `$C00000-$C1FFFF`. The BIOS's vector table starts `0010F300` (SSP) and `00C00402` (reset PC), and the cartridge's own table at `$000000` is the same | [H] wiki "68k memory map"; [O] both files read this way once the bytes of each word are swapped (N10) | `neogeo` |
| N8 | Palette RAM is 8 KiB (two banks of 256 palettes, one visible) at `$400000-$401FFF`, mirrored through `$7FFFFF` | [H] wiki "68k memory map", "Palettes" | `neogeo` |
| N9 | Backup RAM is 64 KiB at `$D00000-$D0FFFF`, battery backed on the MVS (the wiki's `$300000` entry is for Neo Print boards only) | [H] wiki "Backup RAM" | `neogeo` |
| N10 | The BIOS files and the program files of a set hold every 16-bit word byte-swapped (the cartridge header "NEO-GEO" reads `EN-OEG`); the machine swaps them back | [O] the owner's files: the vector table of `sp-s2.sp1` and of three games reads `10 00 00 f3 c0 00 02 04` | `neogeo` |
| N11 | A write of any value to `$300001` (the `$FE0001`-decoded register REG_DIPSW) kicks the watchdog, a frame counter that resets the machine if it runs out; the BIOS's first accesses are such a write | [H] wiki "Watchdog", "Memory mapped registers"; [O] the BIOS's third instruction writes it | `neogeo` (counted only; the reset is not modelled yet) |
| N12 | The video processor's registers are words at `$3C0000` (REG_VRAMADDR), `$3C0002` (REG_VRAMRW, the data port), `$3C0004` (REG_VRAMMOD, added to the address after each write), `$3C0006` (REG_LSPCMODE), `$3C0008`/`$3C000A` (REG_TIMERHIGH/LOW), `$3C000C` (REG_IRQACK: bits acknowledge the vertical blank, timer and reset interrupts) and `$3C000E` (REG_TIMERSTOP) | [H] wiki "Memory mapped registers", "VRAM", "Timer interrupt", "68k interrupts" (search results, 2026-10-31); [O] the BIOS's fourth instruction writes `$3C000C` = 7 | `neogeo` (stored only) |
| N13 | Video RAM is 0x8800 words: a slow part `$0000-$7FFF` and a fast part `$8000-$87FF` | [H?] from memory of the wiki "VRAM" page, to confirm; the read path of REG_VRAMRW is a plain read | `neogeo` |
| N14 | The system registers are odd-byte writes decoded with `$FE0001` into a latch of eight bits: address bits A3-A1 pick the bit and A4 is the value written. The pairs: `$3A0001`/`$3A0011` NOSHADOW/SHADOW, `$3A0003`/`$3A0013` SWPBIOS/SWPROM (the vector table at `$000000-$00007F` is the system ROM's or the cartridge's), `$3A0005`/`$3A0015` and `$3A0007`/`$3A0017` the memory card locks, `$3A0009`/`$3A0019` card register select, `$3A000B`/`$3A001B` BRDFIX/CRTFIX (fix layer and Z80 ROM of the board or of the cartridge), `$3A000D`/`$3A001D` SRAMLOCK/SRAMUNLOCK, `$3A000F`/`$3A001F` PALBANK1/PALBANK0 (which of the two palette banks the window `$400000` shows). Palette RAM is two banks of 8 KiB | [H] wiki "Memory mapped registers", "Vector table swap", "NEO-E0", "Palettes" (search results); `[H?]` the power-on state: bank 0 and the system ROM's vectors are assumed | `neogeo` (shadow, card and fix bits are stored only) |
| N15 | Write-only output registers decoded with `$FE00F1`: REG_POUTPUT `$380001`, REG_SLOT `$380021`, REG_LEDLATCHES `$380031`, REG_LEDDATA `$380041`, REG_RTCCTRL `$380051` (the clock chip's strobe, clock and data lines) | [H] wiki "Memory mapped registers", freemlib `neogeo.inc` and the wiki's 68k ASM defines (search results); [O] the BIOS writes `$380031` = `$FF` early | `neogeo` (stored only) |
