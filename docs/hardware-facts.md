# Neo Geo hardware facts

Every hardware fact the Neo Geo code uses is a row here. Tags: `[D]` datasheet, `[H]` documentation, `[O]` observed in the
reference emulator (FinalBurn Neo, a black box through its libretro core), `[H?]` unresolved. No code, table or constant is
copied from any emulator.

| ID | Fact | Source | Used by |
|---|---|---|---|
| N1 | A cartridge set is a zip whose file extensions name the regions: `.p<n>` the 68000 program, `.s<n>` the fix layer, `.c<n>` sprite data in pairs (odd-numbered file the even bytes, the next file the odd bytes), `.m<n>` the Z80 program, `.v1<n>` the first sample region and `.v2<n>` the second; a set with only single-digit `.v` files has one region. Numbers order the files. Sets seen: Cyber-Lip (P 512 KB, S 128 KB, C 3 MB, M 128 KB, V1 2 MB, V2 512 KB), Fatal Fury (P 640 KB: a 512 KB and a 128 KB file, whose place in the address space is `[H?]`), Aero Fighters 2 (P 2 MB, C 8 MB, V 3 MB) | [O] the file names and sizes of the owner's sets (RomM platform 79) | `neo-set` |
| N2 | The BIOS is one zip of 34 files (`neogeo.zip`: `sp-s2.sp1`, `sp-u2.sp1`, `uni-bios_*.rom`, `000-lo.lo`, `sfix.sfix`, `sm1.sm1` and others); the machine picks one 128 KB 68000 BIOS, the fix tiles `sfix.sfix`, the zoom table `000-lo.lo` and the Z80 BIOS `sm1.sm1`. Which BIOS file FBNeo uses by default and what each is called by the hardware is `[H?]` | [O] the zip's listing; [H?] the roles | none yet |
| N3 | Reference output: FinalBurn Neo v1.0.0.03 (GIT2b0c1c0) libretro core reports 304 x 224 pixels, 59.18 fps, 47995 Hz audio; Cyber-Lip shows the NEO-GEO logo screen (Pro-Gear Spec) at frame 600 | [O] `libretro_run.py --info`, 2026-10-31 | scenarios |
| N4 | Clocks: master 24 MHz; 68000 at 12 MHz, Z80 at 4 MHz, YM2610 at 8 MHz, pixel clock 6 MHz; a frame of 384 x 264 pixel clocks is about 59.185 Hz | [H?] neogeodev wiki from memory, to confirm; [O] 59.18 fps agrees | none yet |
| N5 | The cartridge's program ROM is at `$000000-$0FFFFF` (vectors and the first bank) and a second bank window at `$200000-$2FFFFF`; with a 2 MiB program the two halves are swapped: the file's second MiB is at `$000000` and its first MiB at `$200000` | [H] neogeodev wiki "68k memory map", "P ROM" (found by search, 2026-10-31); [O] Aero Fighters 2's file starts with `20 00 44 01` (a first MiB that is not the vector table) | `neogeo` |
| N6 | Work RAM is 64 KiB at `$100000-$10FFFF`, mirrored through `$1FFFFF` on cartridge systems; its top (`$10F300-$10FFFF`) is used by the BIOS | [H] wiki "68k memory map", "68k user RAM" | `neogeo` |
| N7 | The system ROM is 128 KiB at `$C00000-$C1FFFF`. The BIOS's vector table starts `0010F300` (SSP) and `00C00402` (reset PC), and the cartridge's own table at `$000000` is the same | [H] wiki "68k memory map"; [O] both files read this way once the bytes of each word are swapped (N10) | `neogeo` |
| N8 | Palette RAM is 8 KiB (two banks of 256 palettes, one visible) at `$400000-$401FFF`, mirrored through `$7FFFFF` | [H] wiki "68k memory map", "Palettes" | `neogeo` |
| N9 | Backup RAM is 64 KiB at `$D00000-$D0FFFF`, battery backed on the MVS (the wiki's `$300000` entry is for Neo Print boards only) | [H] wiki "Backup RAM" | `neogeo` |
| N10 | The BIOS files and the program files of a set hold every 16-bit word byte-swapped (the cartridge header "NEO-GEO" reads `EN-OEG`); the machine swaps them back | [O] the owner's files: the vector table of `sp-s2.sp1` and of three games reads `10 00 00 f3 c0 00 02 04` | `neogeo` |
| N11 | A write of any value to `$300001` (the `$FE0001`-decoded register REG_DIPSW) kicks the watchdog, a frame counter that resets the machine if it runs out; the BIOS's first accesses are such a write | [H] wiki "Watchdog", "Memory mapped registers"; [O] the BIOS's third instruction writes it | `neogeo` (counted only; the reset is not modelled yet) |
| N12 | The video processor's registers are words at `$3C0000` (REG_VRAMADDR), `$3C0002` (REG_VRAMRW, the data port), `$3C0004` (REG_VRAMMOD, added to the address after each write), `$3C0006` (REG_LSPCMODE), `$3C0008`/`$3C000A` (REG_TIMERHIGH/LOW), `$3C000C` (REG_IRQACK: bits acknowledge the vertical blank, timer and reset interrupts) and `$3C000E` (REG_TIMERSTOP) | [H] wiki "Memory mapped registers", "VRAM", "Timer interrupt", "68k interrupts" (search results, 2026-10-31); [O] the BIOS's fourth instruction writes `$3C000C` = 7 | `neogeo` (stored only) |
| N13 | Video RAM is 0x8800 words: a slow part `$0000-$7FFF` and a fast part `$8000-$87FF` | [H?] from memory of the wiki "VRAM" page, to confirm; the read path of REG_VRAMRW is a plain read | `neogeo` |
| N14 | The system registers are odd-byte writes decoded with `$FE0001` into a latch of eight bits: address bits A3-A1 pick the bit and A4 is the value written. The pairs: `$3A0001`/`$3A0011` NOSHADOW/SHADOW, `$3A0003`/`$3A0013` SWPBIOS/SWPROM (the vector table at `$000000-$00007F` is the system ROM's or the cartridge's), `$3A0005`/`$3A0015` and `$3A0007`/`$3A0017` the memory card locks, `$3A0009`/`$3A0019` card register select, `$3A000B`/`$3A001B` BRDFIX/CRTFIX (fix layer and Z80 ROM of the board or of the cartridge), `$3A000D`/`$3A001D` SRAMLOCK/SRAMUNLOCK, `$3A000F`/`$3A001F` PALBANK1/PALBANK0 (which of the two palette banks the window `$400000` shows). Palette RAM is two banks of 8 KiB | [H] wiki "Memory mapped registers", "Vector table swap", "NEO-E0", "Palettes" (search results); `[H?]` the power-on state: bank 0 and the system ROM's vectors are assumed | `neogeo` (shadow, card and fix bits are stored only) |
| N15 | Write-only output registers decoded with `$FE00F1`: REG_POUTPUT `$380001`, REG_SLOT `$380021`, REG_LEDLATCHES `$380031`, REG_LEDDATA `$380041`, REG_RTCCTRL `$380051` (the clock chip's strobe, clock and data lines) | [H] wiki "Memory mapped registers", freemlib `neogeo.inc` and the wiki's 68k ASM defines (search results); [O] the BIOS writes `$380031` = `$FF` early | `neogeo` (stored only) |
| N16 | Coin lines, written with any value, decoded with `$FE00F1`: REG_RESETCC1 `$380061`, REG_RESETCC2 `$380063` (coin counters 1 and 2 float), REG_RESETCL1 `$380065`, REG_RESETCL2 `$380067` (coin lockouts 1 and 2 float); the SET registers `$3800E1`, `$3800E3`, `$3800E5`, `$3800E7` sink the same lines | [H] wiki "Memory mapped registers" and a mirror of its table (search results); [O] the BIOS writes `$380065` early | `neogeo` (the four lines are recorded only) |
| N17 | REG_DIPSW (`$300001`, decoded `$FE0081`) reads the hardware DIP switches, active low (0 = on): bit 0 settings mode, 1 two coin chutes, 2 mahjong controller, 3-4 multiplayer link ID, 5 multiplayer, 6 freeplay, 7 freeze; the test button is not here but in REG_STATUS_B / `$300081` | [H] wiki "Hardware DIPs", "Memory mapped registers" (search results); all switches off (`$FF`) is the default here | `neogeo` |
| N18 | REG_STATUS_A (`$320001`, odd-byte read, decoded `$FE0001`): the coin 1, coin 2 and service inputs in the low bits, active low; above them the uPD4990 clock's data and time-pulse bits and the slot-type bits. Nothing pressed reads `$07` here | [H] wiki "Memory mapped registers", "Coin switch", "Service button"; `[H?]` the bit order of the upper bits (the wiki's table is inconsistent in the search results) | `neogeo` |
| N19 | REG_STATUS_A bit 6 is the clock chip's (uPD4990A) time pulse output; the BIOS waits for its rising edge right after the coin registers are set up. The pulse period is selectable in the chip; the BIOS's calendar check expects its edges 57 to 64 frames apart (about one second), so the one-second period (a half period of 12 000 000 master clocks) is used | [O] the BIOS loop at `$C11D94` (`eor`/`and`/`andi.b #$40`) polls it, and with a 64 Hz pulse the BIOS ended in its error screen (code 5 at `$10FD08`); [H] wiki "CALENDAR ERROR" (57-64 frames); `[H?]` phase and the other TP modes | `neogeo` |
| N20 | A frame is 264 lines of 1536 master clocks (384 pixels of 4 clocks), 405 504 clocks, 59.185 Hz at 24 MHz: 8 lines of sync, 16 of top border, 224 active, 16 of bottom border. The vertical blank interrupt is raised where the active lines end (line 248 counting from the sync) | [H] wiki "Display timing", "Frame size" (search results); `[H?]` the exact line of the interrupt; [O] FBNeo reports 59.18 fps | `neogeo` |
| N21 | Interrupt levels on a cartridge system: 3 is pending after reset (the BIOS handles it first), 2 the timer, 1 the vertical blank (a CD system swaps 1 and 2); REG_IRQACK `$3C000C` clears them: bit 0 the reset interrupt, bit 1 the timer, bit 2 the vertical blank, and an interrupt must be acknowledged to be raised again | [H] wiki "68k interrupts", "Timer interrupt" (search results) | `neogeo` |
| N22 | REG_STATUS_B (`$380000`, even-byte read, decoded `$FE00F1`): bits 0-3 the start and select buttons of both players, then the memory card detect and write-protect lines (active low, a card absent or writable reads 1) and bit 7 the system type (1 = MVS, 0 = AES). An MVS with nothing pressed and no card reads `$FF` | [H] wiki "Memory mapped registers" and "68k ASM defines" (search results); `[H?]` the order of the card bits; the MVS is chosen because FBNeo shows the MVS logo screen | `neogeo` |
| N23 | `$300081` (decoded `$FE0081`, REG_SYSTYPE): bit 7 reads the test button (active low), bit 0 tells a 2-slot from a 4 or 6-slot system; the BIOS reads it after the calendar check. Not pressed, reads `$FF` here | [H] wiki "NEO-F0", "Memory mapped registers" (search results); `[H?]` the slot bit's sense and the other bits | `neogeo` |
| N24 | The Z80 sees the sound program (the board's `sm1` or the cartridge's M1, chosen by the BRDFIX/CRTFIX latch bit) at `$0000-$7FFF`, then four bank windows: `$F000-$F7FF` (window 0, 2 KiB units), `$E000-$EFFF` (window 1, 4 KiB), `$C000-$DFFF` (window 2, 8 KiB), `$8000-$BFFF` (window 3, 16 KiB); 2 KiB of RAM at `$F800-$FFFF`. A bank is chosen by a READ of port `$08-$0B` (window 0 to 3): the high byte of the port address (register B) is the bank number | [H] wiki "Z80", "Z80 port map", "NEO-ZMC" (search results) | `neogeo` `sound` |
| N25 | Z80 ports (decoded with `$0C` for reads): `$00` read takes the sound command and acknowledges the NMI, write clears the command; `$04-$07` the YM2610; `$08-$0B` write enables NMIs; `$0C` write sets the reply to the 68000; `$18` write disables NMIs. The 68000 writes REG_SOUND `$320000` to send a command (NMI at `$0066` when enabled) and reads it for the reply; no interrupt is generated for a reply | [H] wiki "Z80 port map", "68k/Z80 communication" (search results); [O] the BIOS sends commands 1 and 3 to the Z80 early | `neogeo` `sound` |
| N26 | The YM2610 has two register pairs: ports 4/5 (SSG, ADPCM-B, FM channels 1 and 2) and ports 6/7 (ADPCM-A, FM channels 3 and 4). Only the writes are kept; the status read returns 0 (not busy, no timer flag) | [H] wiki "Z80/YM2610 interface" (search results); `[H?]` the timers, which the sound program may wait on | `neogeo` `sound` |
| N28 | REG_P1CNT `$300000` and REG_P2CNT `$340000`: the joypad bits (up, down, left, right, A, B, C, D), active low; released reads `$FF` | [H] wiki "Joypad" (search results); `[H?]` the bit order | `neogeo` |
| N29 | A palette word: bit 15 the dark bit, bits 14-12 the least significant bits of red, green and blue, bits 11-8 the other four bits of red, 7-4 of green, 3-0 of blue; a palette is 16 words, colour 0 transparent, and the backdrop is colour 15 of palette 255 | [H] wiki "Palettes" (search results); [O] the BIOS logo screen drawn with it matches FBNeo's | `neogeo` `video` |
| N30 | The fix layer's map is 40 columns of 32 words at `$7000` (column x row), each word the tile in bits 11-0 and the palette in bits 15-12; the visible rows are 2 to 29; a tile is 8x8 pixels in 32 bytes, four stored columns of 8 bytes (one byte per line, two pixels each, the left of the pair in the low nibble) in the order of pixel columns 4-5, 6-7, 0-1, 2-3 | [H] wiki "Fix graphics format" (search results; the column order from a memory of the layout, then confirmed); [O] the BIOS text "MAX 330 MEG..." reads correctly against FBNeo's picture | `neogeo` `video` |
| N31 | A sprite tile is 16x16 pixels in 128 bytes of the interleaved C pair (even bytes the first file, odd bytes the second): four 8x8 blocks of 32 bytes, stored in the order top-right, bottom-right, top-left, bottom-left; a line of a block is 4 bytes holding bitplane 0, bitplane 2, bitplane 1, bitplane 3; bit 0 is the leftmost pixel | [H] wiki "Sprite graphics format" (blocks, planes in two files); [O] found by trying every block and plane order against FBNeo's NEO-GEO logo: the best one matches to 1813 of 11 500 pixel-levels (the next is not close) | `neogeo` `video` |
| N32 | Sprites: SCB1 at `$0000` (64 words a sprite: 32 tiles of tile-low and attribute: palette in bits 15-8, tile bits 19-16 in bits 7-4, vertical flip bit 1, horizontal flip bit 0), SCB2 at `$8000` (shrink), SCB3 at `$8200` (Y in bits 15-7, sticky bit 6, height in tiles bits 5-0), SCB4 at `$8400` (X in bits 15-7); a sticky sprite continues the chain one tile to the right; a sprite's first line on screen is (496 - Y) mod 512 and x is X, both counted from the first visible line and the 320-pixel picture | [H] wiki "Sprites" (search results); [O] the position was found by shifting our picture against FBNeo's (0 pixels across, 0 lines with this formula) | `neogeo` `video` |
| N33 | The host's input reaches the machine through the same registers: the pad directions and buttons in REG_P1CNT/P2CNT (active low), coin 1, coin 2 and service in the low bits of REG_STATUS_A (active low), start and select of both players in the low four bits of REG_STATUS_B (start 1, select 1, start 2, select 2) | [H] wiki "Joypad", "Coin switch", "Service button", "68k ASM defines" (CNT_START1 = 0, CNT_SELECT1 = 1, CNT_START2 = 2, CNT_SELECT2 = 3) | `neogeo` |
| N34 | Reading REG_LSPCMODE (`$3C0006`) gives the raster line counter in bits 15-7 (nine bits: the vertical sync band is `$0F8-$0FF`, so the counter is `$0F8` plus the line from the start of the sync and runs to `$1FF`) and the auto-animation counter in bits 2-0; writing it sets the animation speed in bits 15-8 (the counter steps every speed + 1 frames) and bit 3 stalls it; a sprite tile whose attribute has bit 3 set takes its low two bits from the counter, bit 2 its low three | [H] wiki "Display timing", "Auto animation" (search results); `[H?]` the counter's phase | `neogeo` |
| N35 | The write-only registers (the system latch `$3A00xx`, REG_POUTPUT/SLOT/LED/RTC and the coin lines `$380xxx`) are read by the 68000's `clr.b` before it writes them; the read must not stop the machine. It returns `$FF` here (an open bus) | [O] Fatal Fury reads `$3A0001` at start-up; `[H?]` the value on the bus | `neogeo` |
